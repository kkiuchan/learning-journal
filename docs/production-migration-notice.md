# Learning Journal 本番環境移行のお知らせ

## 📢 重要なお知らせ

いつもLearning Journalをご利用いただき、ありがとうございます。

この度、サービスの本格運用開始に伴い、決済システムをテスト環境から本番環境に移行いたしました。

## 🔄 移行に伴う変更点

### 既存ユーザーの皆様へ

**サブスクリプション状況のリセット**

- テスト環境でのサブスクリプション情報は本番環境に引き継がれません
- 全ユーザーが一度「無料プラン」にリセットされます

**プロプランを継続ご利用の場合**

- 改めてプロプランへのお申し込みが必要です
- 既存のデータ（学習記録）はすべて保持されます

## 💳 新しい課金システムの特徴

**安全性の向上**

- 本番環境のStripe決済システムで安全な課金処理
- 実際のクレジットカード決済が可能

**機能追加**

- カスタマーポータルでのサブスクリプション管理
- 詳細な請求履歴の確認
- 支払い方法の変更・更新

## 🎯 プロプラン再登録手順

1. **ログイン**

   - Learning Journalにログイン

2. **プラン選択**

   - 「料金プラン」ページにアクセス
   - 「プロプランを始める」をクリック

3. **決済情報入力**

   - Stripeの安全な決済フォームで情報入力
   - クレジットカード情報を登録

4. **利用開始**
   - 決済完了後、即座にAI機能が利用可能

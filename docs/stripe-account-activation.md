# Stripe アカウント本番環境有効化ガイド

## 🚨 現在の状況

**エラー**: `Your account cannot currently make live charges.`

このエラーは、Stripeアカウントが本番環境での課金を許可されていないことを示しています。

## 📋 本番環境有効化の要件

### 1. **アカウント情報の完成**

**事業者情報**:

- [ ] 事業者名
- [ ] 所在地（特定商取引法記載と一致）
- [ ] 電話番号
- [ ] ウェブサイトURL: `https://www.learning-journal-app.com`

**事業内容**:

- [ ] 業種: オンライン教育・学習支援サービス
- [ ] 商品・サービス: サブスクリプション型学習記録アプリ
- [ ] 月額料金: 680円

### 2. **銀行口座情報**

**必要書類**:

- [ ] 銀行口座情報
- [ ] 口座名義確認
- [ ] 金融機関コード・支店コード

### 3. **本人確認書類**

**個人事業主の場合**:

- [ ] 運転免許証 または パスポート
- [ ] マイナンバーカード（表面のみ）

**法人の場合**:

- [ ] 法人登記簿謄本
- [ ] 代表者の身分証明書

### 4. **税務情報**

**日本の事業者**:

- [ ] 税務情報の入力
- [ ] 消費税の取り扱い設定

## 🔧 設定手順

### Step 1: ダッシュボードアクセス

1. [Stripe ダッシュボード](https://dashboard.stripe.com/) にログイン
2. 左上で**本番環境**に切り替え
3. 右上のアカウント名をクリック → **アカウント設定**

### Step 2: 必須情報の入力

1. **アカウントの詳細**

   - 事業者情報を入力
   - 事業内容を詳細に記載

2. **銀行口座**

   - 売上金受け取り用口座を登録

3. **税務情報**
   - 適切な税務設定を選択

### Step 3: 本人確認

1. **本人確認** セクションで書類をアップロード
2. Stripeからの審査完了を待機

## ⏱️ 審査期間

**通常の審査期間**: 1-3営業日
**追加書類が必要な場合**: 1週間程度

## 🔄 一時的な対応

審査完了まで**テスト環境で動作確認**を継続：

```bash
# テスト環境の環境変数に戻す（Vercelで設定）
STRIPE_SECRET_KEY=sk_test_...
STRIPE_PUBLISHABLE_KEY=pk_test_...
```

# お問い合わせフォーム - セットアップガイド

## 概要

Learning Journalのお客様サポート用お問い合わせフォームの実装と設定方法について説明します。

## 実装機能

### ✅ 実装済み機能

1. **お問い合わせフォーム** (`/contact`)

   - バリデーション付きフォーム
   - カテゴリ別問い合わせ（一般・技術・請求・機能提案）
   - リアルタイムエラー表示

2. **自動メール送信**

   - 管理者への通知メール（返信先：お客様メールアドレス）
   - お客様への自動返信メール（返信先：管理者メールアドレス）

3. **UI統合**
   - フッターにお問い合わせリンク追加
   - モバイル対応
   - ダークモード対応

## 必要な環境変数

### Vercel環境での設定

以下の環境変数を設定してください：

```bash
# 管理者用メールアドレス（お問い合わせを受信）
ADMIN_EMAIL=your-admin@example.com

# サポート用メールアドレス（ADMINが未設定の場合のフォールバック）
SUPPORT_EMAIL=support@your-domain.com

# Resend API キー（既存）
RESEND_API_KEY=re_xxxxx

# アプリケーションURL（既存）
NEXT_PUBLIC_APP_URL=https://your-domain.com
```

### 設定方法

1. **Vercelダッシュボード**での設定

   ```
   プロジェクト → Settings → Environment Variables
   ```

2. **ローカル開発**での設定
   ```bash
   # .env.local に追加
   ADMIN_EMAIL=bandman.gh.bs.dk.lav@gmail.com
   SUPPORT_EMAIL=bandman.gh.bs.dk.lav@gmail.com
   ```

## メール送信フロー

### 1. お客様がフォーム送信

```
お客様 → フォーム送信 → API (/api/contact)
```

### 2. 管理者への通知メール

```
件名: 【お問い合わせ】{件名}
送信先: {ADMIN_EMAIL}
返信先: {お客様のメールアドレス}
内容: お問い合わせ詳細（名前、メール、カテゴリ、内容）
```

### 3. お客様への自動返信メール

```
件名: 【Learning Journal】お問い合わせを承りました - {件名}
送信先: {お客様のメールアドレス}
返信先: {ADMIN_EMAIL}
内容: 受付確認と今後の流れ
```

## 運用方法

### お問い合わせへの返信

1. **管理者宛メールから直接返信**

   - 通知メールの「返信」ボタンを使用
   - 自動的にお客様に返信される

2. **カテゴリ別対応**
   - **一般的なお問い合わせ**: 基本的な質問・要望
   - **技術的な問題**: バグレポート・動作不良
   - **請求・支払いについて**: サブスクリプション関連
   - **機能追加のご提案**: 新機能要望

### 返信時間の目安

- **通常**: 1〜2営業日以内
- **急用**: 当日〜翌営業日
- **技術的問題**: 詳細確認後、2〜3営業日

## フォームバリデーション

### 必須項目

- お名前（1文字以上）
- メールアドレス（有効な形式）
- カテゴリ（選択必須）
- 件名（1文字以上）
- お問い合わせ内容（10文字以上）

### エラーハンドリング

- クライアントサイド: リアルタイムバリデーション
- サーバーサイド: Zodによる厳密なバリデーション
- ユーザーフレンドリーなエラーメッセージ

## テスト方法

### 1. フォーム送信テスト

```bash
# 開発環境でテスト
curl -X POST http://localhost:3000/api/contact \
  -H "Content-Type: application/json" \
  -d '{
    "name": "テストユーザー",
    "email": "test@example.com",
    "subject": "テスト問い合わせ",
    "category": "general",
    "message": "これはテスト用のお問い合わせです。"
  }'
```

### 2. メール送信確認

1. 管理者メールアドレスに通知が届くか確認
2. お客様メールアドレスに自動返信が届くか確認
3. 返信先アドレスが正しく設定されているか確認

## トラブルシューティング

### よくある問題

1. **メールが送信されない**

   - `RESEND_API_KEY`が正しく設定されているか確認
   - Resendのダッシュボードでクォータ制限を確認

2. **管理者メールが届かない**

   - `ADMIN_EMAIL`環境変数が設定されているか確認
   - 迷惑メールフォルダを確認

3. **返信メールの宛先が間違う**
   - `replyTo`設定を確認
   - メールクライアントで返信先を確認

### ログ確認

```bash
# Vercelでのログ確認
vercel logs --follow

# ローカルでの確認
# コンソールに出力される送信ログを確認
```
